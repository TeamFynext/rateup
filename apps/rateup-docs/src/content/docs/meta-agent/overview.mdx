**Overview** is where an agent starts. Nothing else in this section does anything until a number is
onboarded — onboarding is what creates the agent at Meta and returns the agent id every other call
is scoped to.

---

## Check Eligibility

Not every WhatsApp number may run a Business Agent. Meta decides.

<Steps>
  <Step>Pick the number from **Select WhatsApp number**.</Step>
  <Step>Enter the **Consumer phone number** in E.164 format, including the country code.</Step>
  <Step>Click **Check with Meta**.</Step>
</Steps>

The card then reads either *"Meta confirmed this number is eligible."* or *"Meta says this number is
not eligible for the Business Agent yet."* **Re-check** asks again — eligibility can change without
you doing anything.

---

## Onboard the Agent

Once the number is eligible, **Onboard agent** creates it at Meta. The header badge changes to
**ONBOARDED** and the remaining pages become useful.

**Re-onboard** repeats the call for a number that is already onboarded — use it if the agent at Meta
was removed or has to be recreated.

<Callout type="warn">
  Onboarding does not switch the agent on. It exists but answers nobody until you enable rollout —
  see [Settings](/meta-agent/settings). Give it knowledge and skills first.
</Callout>
