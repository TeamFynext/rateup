The **Meta AI Agent** answers your customers on WhatsApp using Meta's own Business Agent. It runs at
Meta, not in RateUp — you configure what it knows, what it may do and who it is allowed to talk to,
and Meta does the answering.

The section opens on a **setup guide** that walks you through it in order. In the sidebar, every
step is its own row under **Meta AI Agent**, grouped as **Get started**, **Teach your agent**, **Go
further** and **Test and go live**, with a tick on each finished step and an **Agent setup** meter
at the foot of the panel.

<ScreenShot src="/docs/screenshots/meta-agent/setup-guide.png" alt="Meta AI Agent setup guide for a live agent, with the sidebar steps and Agent setup meter" />

<Callout type="info">
  The section only appears if your team has the AI chatbot feature. It also needs a connected
  WhatsApp number — without one, every page shows **Connect WhatsApp first**.
</Callout>

---

## Which Number You Are Configuring

Every page works against one WhatsApp number. With a single number connected, the header simply
names it; with several, pick one from the **Select WhatsApp number** picker in the header. The
choice sticks as you move between pages.

Next to the title, a badge says where that number's agent stands:

| Badge | Meaning |
|-------|---------|
| **Not set up** | No agent has been created at Meta for this number yet |
| **Off** | The agent exists but **Agent is on** is switched off, so it answers nobody |
| **Live** | The agent exists and is answering customers |
