## Choice Questions

RateUp provides variety of multiple choice question types. These question types allow you to create choices for questions from which user can select one or more choices depending on the question type.

There are 6 type of Choice questions.

#### 1. Single Select

Single select allow respondent to select only one choice from given choices.
  
    
    To add Single Select Question,

    1. Click on `Add Content` in edit tab of selected Survey and then click on **`Single Select`** under Choice Questions.  
    2. A blank Single Select question will be created.
    3. Give question in text editor.
    4. Enter choice in the below field and then click `Add Choice`. Similarly add any number of choices you want. 
    5. If you want an other field, you can enable Other button. It will provide a text field, where user can give other option which is not in the choices.
    6. You can also import the choices from an xlsx file. To do that, click on `Choose .xlsx file` button and then upload your file.
    7. If multiple langauges are selected, Switch the language in the right of text editor and repeat the steps 3 to 5 in the selected language.

#### 2. Multiple Select

Multiple select allow respondent to select one or more choices from given choices.

   To add Multiple Select Question,

    1. Click on `Add Content` in edit tab of selected Survey and then click on **`Multiple Select`** under Choice Questions.
    2. A blank Multiple Select question will be created.
    3. Give question in text editor.
    4. Enter choice in the below field and then click `Add Choice`. Similarly add any number of choices you want. 
    5. If you want an other field, you can enable Other button. It will provide a text field, where user can give other option which is not in the choices. 
       Here user can also select choice and provide other value.
    6. You can also import the choices from an xlsx file. To do that, click on `Choose .xlsx file` button and then upload your file.
    7. If multiple langauges are selected, Switch the language in the right of text editor and repeat the steps 3 to 5 in the selected language.

#### 3. Dropdown Single Select

Dropdown Single Select is similar to single select. It allow respondent to select one choice from given choices in dropdown list. 

   To add Dropdown Single Select Question,

    1. Click on `Add Content` in edit tab of selected Survey and then click on **`Dropdown Single Select`** under Choice Questions.
    2. A blank Dropdown Single Select question will be created.
    3. Give question in text editor.
    4. Enter choice in the below field and then click `Add Choice`. Similarly add any number of choices you want. 
    5. You can also import the choices from an xlsx file. To do that, click on `Choose .xlsx file` button and then upload your file.
    6. If multiple langauges are selected, Switch the language in the right of text editor and repeat the steps 3 & 4 in the selected language.

#### 4. Dropdown Multiple Select

Dropdown Multiple select  is similar to Multiple Select. It allow respondent to select one or more choices from given choices in dropdown list.

   To add Dropdown Multiple Select Question,

    2. A blank Dropdown Multiple Select question will be created.
    3. Give question in text editor.
    4. Enter choice in the below field and then click `Add Choice`. Similarly add any number of choices you want. 
    5. You can also import the choices from an xlsx file. To do that, click on `Choose .xlsx file` button and then upload your file.
    6. If multiple langauges are selected, Switch the language in the right of text editor and repeat the steps 3 & 4 in the selected language.

#### 5. Picture Choice

Picture Choice allow respondent to select picture choices from given choices.

   To add Picture Choice Question,

    1. Click on `Add Content` in edit tab of selected Survey and then click on **`Picture Choice`** under Choice Questions.
    2. A blank Picture Choice question will be created.
    3. Give question in text editor.
    4. Enter label for choice in the below field and upload an image for the choice, then click `Add Choice`. Similarly add any number of choices you want. 
    5. If multiple langauges are selected, Switch the language in the right of text editor and repeat the steps 3 & 4 in the selected language.

#### 6. Single Select Grid

Single select Grid allow respondent to select only one choice from given choices for each questions. Here you can provide multiple question for same set of choices.

   To add Single Select Grid Question,

    1. Click on `Add Content` in edit tab of selected Survey and then click on **`Single Select Grid`** under Choice Questions.
    2. A blank Single Select Grid question will be created.
    3. Give question title in text editor.
    4. Enter question in the field under the Add Questions. Click `Add Question`. Similarly add any number of questions you want.
    5. Enter choice in the field under Add Choices and then click `Add Choice`. Similarly add any number of choices you want. 
    6. If multiple langauges are selected, Switch the language in the right of text editor and repeat the steps 3 to 5 in the selected language.
