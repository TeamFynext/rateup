## Logic Jump

**Logic Jump** allows you to customize survey flows based on respondents' answers, creating personalized survey experiences.

### Supported Question Types:

- Rating
- Smiley
- Yes or No
- Like or Dislike
- Opinion Scale
- Multiple Select
- Single Select
- Dropdown Single Select
- Dropdown Multiple Select

## Google Review Setup

Integrate **Google Reviews** directly into your surveys to collect feedback seamlessly.

### Supported Question Types:

- Rating
- Smiley
- Opinion Scale

## Custom Validation

**Custom Validation** ensures data accuracy by enforcing specific rules for respondent answers.

### Supported Question Types:

- Text
- Large Text
- Number
- Multi Text Input
- Opt In

### Available Validations:

- Length
- Word Count
- Text Type
- Required

## Exporting Responses

Export survey responses for further analysis and reporting.

### 1. Google Sheet Sync

Sync responses to Google Sheets for real-time data management.

### 2. Excel Download

Download responses as an Excel (.xlsx) file for offline analysis.

### 3. Import Contacts

Import contacts from survey responses into your WhatsApp contacts list.

## Variables

**Variables** enable dynamic survey customization by storing and utilizing user input.

### Types of Variables:

#### 1. Default Variables

Capture responses from specific question types for personalized survey paths.

##### Supported Question Types:

- Contact
- Text
- Large Text
- Number
- Date
- Photo
- Rating
- Smiley
- Yes or No
- Like or Dislike
- Opinion Scale
- Testimonial
- Terms & Conditions

#### 2. Custom Variables

Define and use personalized variables across all survey questions.
