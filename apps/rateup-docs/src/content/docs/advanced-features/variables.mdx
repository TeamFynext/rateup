---
title: "Variables"
---

Variables allow you to create dynamic and personalized questions by storing user input and then using that input to tailor subsequent questions or statements.

#### Types of Variables

  ##### 1. Default Variables
                 Default Variables are created when the questions are created which stores response of that question. It is not available to all questions.
    Question Types which support Default Variables are :
        - **Contact**
        - **Text** 
        - **Large Text** 
        - **Number**
        - **Date** 
        - **Photo** 
        - **Rating** 
        - **Smiley** 
        - **Yes or No** 
        - **Like or Dislike** 
        - **Opinion Scale** 
        - **Testimonial**
        - **Terms & Conditions** 

  The question can only access default variables which is previous to that. There question will not have any default variable to be accessible.

  #####  2. Custom Variables

  RateUp allows creation of custom variable which can be used in questions. You can assign any value to the variable.

  To create a custom variable, 
    - Go to any question and click on `Actions` in the bottom.
    - Click on Variables.
    - Click on `Add Variables` on right to the custom variable.
    - Give a name and value for the variable.
    - Name of the variable only accepts alphanumeric characters and underscore. It will not accept any spaces and special characters.

The custom variables are accessible to all questions in a survey.
