side holds the actions.

| Icon | Action | What it does |
|------|--------|--------------|
| 🔍 | **Search** | Find tickets by contact name or phone number |
| ✅ | **Select Chats** | Turn on selection mode for bulk actions |
| ⬇️ | **Download Chats** | Export conversation history |
| 🔄 | **Refresh** | Reload the list |
| ➕ | **New** | Add a WhatsApp contact and start a conversation |

Below them, a second row shows the **count for the current view** on the left and the **sort**
control on the right.

<Callout type="info">
  The count comes from the server, so it reflects the entire view — not just the rows loaded so
  far. While a search is running it shows the number of matching rows instead. In **Spam** it counts
  contacts, because that tab lists one row per contact.
</Callout>

Filtering is **not** in this toolbar. Channel, lifecycle, label, user and team filters live in the
sidebar — see [Sidebar Filters](/inbox/inbox-filter).

## Search

<Steps>
<Step>
Click the **search** icon. The search bar slides over the toolbar.
</Step>
<Step>
Type a contact name or phone number. Results narrow as you type.
</Step>
<Step>
Click the **✕** to clear the search and restore the full view.
</Step>
</Steps>

Search runs **within the current view**. To search everything — open and closed — switch to
[**All**](/inbox/inboxview/all) first.

/>

| Group | Options |
|-------|---------|
| **Message received** | Newest first · Oldest first |
| **Message created** | Newest first · Oldest first |

**Newest first** is the default and suits day-to-day work. Switch to **oldest first** when you are
hunting for tickets that have been waiting too long.

## Bulk Selection

<Steps>
<Step>
Click the **select** (✅) icon. Checkboxes appear on every row.
</Step>
<Step>
Tick the tickets you want to act on.
</Step>
<Step>
Apply the action — assigning several tickets to one person at once is the common case.
</Step>
<Step>
Click the select icon again to leave selection mode.
</Step>
</Steps>

Selection mode is cleared automatically when you switch views. It is not offered in **Spam** — a
flagged contact's tickets are already closed, so there is nothing to assign.

## Exporting

Click the **download** icon to export conversation history.

Set the constraints — date range, message types and the filters currently applied — and download
the file.

<Callout type="warn">
  Exports can include private notes depending on the message types you select. Check before sharing
  a file outside the company.
</Callout>

Messages that were [deleted on WhatsApp](/inbox/responding-to-conversation) keep their row in the
export but their text is withheld — the cell reads *"This message was deleted"*.

## Adding a Contact

<ScreenShot
  src={`/docs/screenshots/inbox/add-whatsapp-contact.png`}
  alt="Add new WhatsApp contact"
  width={550}
/>

<Steps>
<Step>
Click **New** (➕) in the toolbar.
</Step>
<Step>
Enter the full name, WhatsApp number, email (optional) and lifecycle stage.
</Step>
<Step>
Click **Start Conversation**.
</Step>
</Steps>

A ticket is created immediately and appears in the Inbox.

<Callout type="info">
  Starting a conversation with someone who has not messaged you first means there is no open
  24-hour window — your first message must be an approved
  [template](/inbox/send-templates).
</Callout>

---

## Refreshing

The Inbox updates live, but the **refresh** icon forces a reload. Use it if a colleague tells you
about a ticket you cannot see, or after a bulk change made elsewhere.
