---
title: "WhatsApp"
---

RateUp's WhatsApp feature is designed to enhance user engagement and convenience by enabling the creation of surveys accessible directly through WhatsApp. This integration leverages the popularity and widespread usage of WhatsApp, providing a seamless experience for participants to respond to surveys without the need for additional apps or complicated access methods.

RateUp allows following features

#### 1. Flows 
          - Allows to create survey by screens which can be shared in whatsapp and user can respond from whatsapp itself.
#### 2. Templates
          - A WhatsApp Template is a pre-approved message format for sending notifications, updates, and alerts. It ensures consistent and compliant communication and can include placeholders for personalized content.
#### 3. Automated Reply
          - It allows to create automated reply for the whatsapp message
#### 4. Inbox
          - It gives whatsapp chat facility for your account. You can get message and sent message from RateUp itself by utilizing this facility. 
#### 5. Campaign
          - A Campaign lets you share a Template with a selected audience all at once, and it can be scheduled for a future time or sent immediately.
#### 6. Contacts
          - In order to store the contact details of people, RateUp provides contact feature where you can store contacts and create groups.
