## Who Can Change What

What each person can do comes from their role, plus any abilities fine-tuned for them — see
[Members & Roles](/settings/users). By default:

| Area | Who |
|------|-----|
| Own profile, password and notifications | Everyone |
| Invite people · add people to teams | Managers, Admins, the Owner |
| Change roles and abilities · pause or remove people | Admins, the Owner |
| Create or delete teams · team channel access | Admins, the Owner |
| Business details and hours · integrations · the webhook | Managers, Admins, the Owner |
| Channels | Admins, the Owner |
| API keys | Admins, the Owner |
| Billing | Admins, the Owner |
| Transferring or deleting the organisation | The Owner only |

Managers act only within their own teams; Admins and the Owner reach every team.

<Callout type="warn">
  Changes here affect people immediately: an ability removed in **Members** or a channel taken off a
  team applies to that person straight away.
</Callout>

## Common Tasks

| I want to… | Go to |
|-----------|-------|
| Add a new agent | [Members & Roles](/settings/users) → **Invite** |
| Stop someone using the Inbox | [Members & Roles](/settings/users#fine-tune-one-persons-abilities) → fine-tune their abilities |
| Stop getting emails about something | [Notifications](/settings/notifications) |
| Connect a second WhatsApp number | [Channels](/settings/channels) |
| Send events to my own system | [Integrations](/settings/integrations#webhook) → Webhook |
| Build against the REST API | [External API](/external-api) — keys in [Integrations → API Service](/settings/integrations#api-service) |
| Change my password | [Security](/settings/security) |
| Get more active contacts or campaign credits | [Billing](/settings/billing) → **Buy a pack** |
