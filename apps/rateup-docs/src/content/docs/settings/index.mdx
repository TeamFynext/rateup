## Who Can Change What

| Area | Who |
|------|-----|
| Own profile, own password | Everyone |
| Business details, users, teams | Admins |
| Channels, integrations | Admins |
| Billing | Admins |
| Deleting the organisation | The organisation owner |

<Callout type="warn">
  Changes here affect everyone in the organisation. A permission removed in **Users** or a feature
  switched off in **Teams** takes effect for that person immediately.
</Callout>

## Common Tasks

| I want to… | Go to |
|-----------|-------|
| Add a new agent | [Users](/settings/users) → **Add New User** |
| Stop someone seeing the Inbox | [Teams](/settings/teams) → Feature Access |
| Connect a second WhatsApp number | [Channels](/settings/channels) |
| Send order data to my own system | [Integrations](/settings/integrations) → Webhook |
| Build against the REST API | [External API](/external-api) |
| Change my password | [Security](/settings/security) |
| Buy more messages | [Billing](/settings/billing) → **Buy Addons** |
