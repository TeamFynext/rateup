**Surveys** builds the surveys and forms you send to customers — feedback requests, lead capture,
registrations, NPS.

Surveys were previously called Web Forms. Open them from **Surveys & Links → Surveys** in the
sidebar; the same group holds [QR codes and Link-in-bio Pages](/qr-studio).

They run in a browser, so they work anywhere: a QR code on a receipt, a link in a WhatsApp message,
an email, your website.

## The Editor

Every survey opens into the same tabbed editor:

| Tab | For |
|-----|-----|
| **Questions** | Building the survey |
| **Edit Theme** | Colours, fonts and logo |
| **Settings** | Behaviour and access |
| **Share** | Getting it in front of people |
| **Responses** | What people submitted |
| **Analytics** | Charts and NPS analysis |
| **Team Analytics** | The same results compared across teams |

Questions, theming and settings are separate tabs, so you can restyle a survey without touching what
it asks.

## Surveys vs WhatsApp Flows

Both collect structured answers. They suit different moments:

| | Surveys | [WhatsApp Flows](/whatsapp/flows) |
|---|-----------|-----------------------------------|
| **Runs in** | A browser | Inside WhatsApp |
| **Reach** | Anyone with the link | People messaging you on WhatsApp |
| **Length** | Handles longer surveys | Best kept very short |
| **Design control** | Full theming | WhatsApp's styling |
| **Best for** | Detailed feedback, public surveys | Quick in-conversation capture |

<Callout type="info">
  If the person is already in a WhatsApp conversation, a flow gets more completions. If you are
  reaching people by QR code, email or your website, use a survey.
</Callout>
