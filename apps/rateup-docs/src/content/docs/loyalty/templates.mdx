---
title: "Message Templates"
description: Loyalty templates are now the Templates tab on Loyalty › Messages.
---

The loyalty template library is **Messages** › **Templates**. The old `/dashboard/loyalty/templates`
address opens that tab; the editor behind each template is still at
`/dashboard/loyalty/templates/` followed by the template's id. See
[Messages](/loyalty/messages#manage-the-templates).
