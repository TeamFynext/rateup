---
title: "WhatsApp Commands"
description: Loyalty keyword commands are now the Replies tab on Loyalty › Messages.
---

**Commands** became **Messages** › **Replies** — the keywords customers text, such as `points` or
`refer`, and what the programme answers. The old `/dashboard/loyalty/command` address opens that
tab. The registration link moved to [Settings](/loyalty/settings). See
[Messages](/loyalty/messages#set-up-keyword-replies).
