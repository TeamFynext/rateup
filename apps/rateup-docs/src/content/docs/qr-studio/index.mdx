**QR Studio** is how you get people from the physical world into RateUp — a QR on a table tent, a
link in a bio, a code on a receipt.

Both tools are **trackable**: you can change where they point after printing, and you can see how
often they are used.

## Which One Do I Want?

| Situation | Use |
|-----------|-----|
| A printed code on a table, receipt or poster | **QR Creator** |
| One link in an Instagram bio pointing at several things | **Access Links** |
| A code you may need to redirect later | **QR Creator** — the destination is editable |
| Several campaigns running at once, one entry point | **Access Links** |

You can combine them: generate a QR that points at an access link, and change what sits behind it
whenever the campaign changes — without reprinting anything.
