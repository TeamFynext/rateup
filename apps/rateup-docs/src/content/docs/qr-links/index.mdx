**QR & Links** gets people from the physical world into RateUp: a code on a table tent, a link in
an Instagram bio, a sticker on a receipt.

Both tools are **trackable**. A QR code counts its scans and can be pointed somewhere new after it
is printed; a link page counts its visits and the clicks on each of its buttons.

QR codes were previously called **QR Creator**, and Link-in-bio Pages were previously called
**Access Links**, then **Link pages**; the section itself was once **QR Studio**.

## Which One Do I Want?

| Situation | Use |
|-----------|-----|
| A printed code on a table, receipt or poster that opens one page | **QR codes** |
| One link in an Instagram bio pointing at several things | **Link-in-bio Pages** |
| A code you may need to point somewhere else later | **QR codes**: the destination is editable |
| Letting customers pick which survey to fill in | **Link-in-bio Pages**: add each survey as a button |
| A printed code that opens several choices | **Link-in-bio Pages**: every page has its own QR code on its **Share** tab |

You can combine them: point a QR code at a link page, and change what sits behind it whenever the
campaign changes, without reprinting anything.

---

## Getting In

Both tools live in the sidebar's **Surveys & Links** group, next to [Surveys](/surveys):
**Surveys & Links → QR codes** (`/dashboard/qr-codes`) and **Surveys & Links → Link-in-bio Pages**
(`/dashboard/link-pages`). Every member sees them while the **QR & Links** feature is switched on
under [Customize Menu](/settings/customize-menu); no role ability gates them.
