## When Bulk Actions Are Available

Bulk actions appear when one or more contacts are selected from the Contacts List.

<ScreenShot
  src={`${CDN}/docs/screenshots/contacts/contact-selected.png`}
  alt="Bulk actions enabled after selecting contacts"
/>

To enable bulk actions:

1. Open the **Contacts List**
2. Select one or more contacts using the checkboxes
3. Bulk action options appear at the top

---

## Available Bulk Actions

The following actions are available for selected contacts:

- **Add to Group**
- **Apply Label**
- **Update Lifecycle Stage**
- **Delete**

---

## Add to Group

Use this action to add selected contacts to an existing group.

<ScreenShot
  src={`${CDN}/docs/screenshots/contacts/add-to-group.png`}
  alt="Add contacts to group modal"
 width={400}
/>

To add contacts to a group:

1. Select the required contacts
2. Click **Add to Group**
3. Choose a group from the dropdown
4. Click **Save** to confirm  
5. Click **Cancel** to exit without applying changes

Selected contacts are added to the chosen group immediately.

---

## Apply Label

Labels help identify and distinguish contacts.

<ScreenShot
  src={`${CDN}/docs/screenshots/contacts/apply-labels.png`}
  alt="Apply labels to contacts modal"
   width={400}
/>

To apply labels:

1. Select the contacts
2. Click **Apply Label**
3. Select one or more labels
4. Use the search field to quickly find labels
5. Click **Apply** to assign labels  
6. Click **Cancel** to discard changes

Applied labels appear in the **Label** column for all selected contacts.

---

## Update Lifecycle Stage

Lifecycle stages represent the current status of a contact.

<ScreenShot
  src={`${CDN}/docs/screenshots/contacts/update-lifecycle.png`}
  alt="Update lifecycle stage modal"
   width={400}
/>

To update lifecycle stage:

1. Select the required contacts
2. Click **Update Lifecycle Stage**
3. Choose a lifecycle stage from the list
4. Click **Save**

The selected lifecycle stage is applied to all chosen contacts.

---

## Delete Contacts

- Permanently removes selected contacts
- This action cannot be undone
- Use with caution when deleting multiple contacts

---

## Why Bulk Actions Matter

Bulk actions help teams:

- Update multiple contacts quickly  
- Maintain consistent labels and lifecycle stages  
- Organize contacts efficiently  
- Reduce repetitive manual work
