**Conditions** are the `IF` part of a rule, set on the builder's **If** step — *"Only if…"*. A
**Message Received** rule needs at least one; for the other triggers they are optional, and a rule
with none fires on every occurrence of its trigger.

## What You Can Test

| Field | Checks | Operators |
|-------|--------|-----------|
| **Message Body** | The text of the message — **All Messages**, or a **Custom keyword** | Contains, Equals, Starts With, Ends With |
| **Contact Email** | The contact's email address | Contains, Equals, Starts With, Ends With |
| **Contact Group** | A group the contact belongs to | Equals |
| **Contact Label** | A label on the contact | Equals |
| **Lead Stage** | The contact's stage on a [pipeline](/pipeline) | Equals |
| **Contact Lifecycle (legacy)** | The contact's lifecycle stage — shown only on conditions that already use it | Equals |

An **Instagram Comment** rule can test only **Message Body** — the comment text.

<Callout type="info">
  **Contains** is the right default for message text. **Equals** on a message body almost never
  matches — real customers do not send exactly one word.
</Callout>

## Combine Conditions in Blocks

Conditions live in numbered blocks — **Block 1**, **Block 2** — added with **Add condition block**.

| Where | Setting | Meaning |
|-------|---------|---------|
| Inside a block | **Match all** | Every condition in the block must be true (AND) |
| Inside a block | **Match any** | At least one must be true (OR) |
| Between blocks (two or more) | **Match all** / **Match any** | Whether every block, or any one, must pass |

**Match any** is how you catch the several ways people phrase the same thing — *refund*, *money
back*, *return*. **Match all** is how you narrow — a message containing "refund" **and** a contact
labelled *VIP*.

The same condition twice in one block is rejected: *"Duplicate conditions are not allowed"*. On a
**Message Received** rule the last block cannot be deleted.

## Conditions for Other Triggers

Some triggers replace the blocks with their own settings on the **If** step:

| Trigger | The If step shows |
|---------|-------------------|
| **Shopify Event** | **Product Filter (optional)** — and, for **On abandoned checkouts**, **Send after** and **Only buyers who accepted marketing** ([details](/automation/abandoned-cart-reminders)) |
| **WooCommerce Event** | **Product Filter (optional)** |
| **Instagram Comment** | The comment source, **Apply to** **All posts** or **Specific posts**, plus Message Body blocks |
| **Instagram Story Mention** | **Apply to** all or specific stories |
| **ig.me Link Opened** | The **Link name** |

## Write Conditions That Actually Fire

- **Test lowercase and common misspellings** — customers do not proofread
- **Prefer a few broad keywords over many exact ones**
- **Watch for accidental matches** — a rule on "no" will fire constantly
- **Use All Messages deliberately** — combined with a reply action it answers every single message
