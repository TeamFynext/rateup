# Custom Validation

Custom Validation feature allow you to provide validations for the response.

Question Types which support custom validation are :
 
  - **Text** 
  - **Large Text** 
  - **Number**
  - **Multi Text Input**
  - **Opt In**

#### Available validations

 - **Length** : You can set a maximum and minimum length for a input
 - **Word Count** : You can set a maximum and minimum number of words the response should have. 
 - **Text Type** : You can set type of the input. Availables types are Numbers, Letters and Numbers_&_Letters
 - **Required** : Specifies whether the question is mandatory to attend.
