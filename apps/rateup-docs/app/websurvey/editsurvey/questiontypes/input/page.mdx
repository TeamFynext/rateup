## Input Questions
RateUp provides a variety of open-ended where respondent can give answer in different forms. 

There are 7 types of Input questions available.

#### 1. Text Input

It is best suitable for questions which has to take single line of response. 

  To add Text Input Question,

    1. Click on `Add Content` in edit tab of selected Survey and then click on **`Text Input`** under Input Questions.
    2. A blank Text Input question will be created.
    3. Give question title in text editor.
    4. If multiple langauges are selected, Switch the language in the right of text editor and repeat the steps 3 in the selected language.

#### 2. Large Text

It is best suitable for questions which has to take multiple line of response. 

  To add Large Text Question,

    1. Click on `Add Content` in edit tab of selected Survey and then click on **`Large Text`** under Input Questions.
    2. A blank Large Text question will be created.
    3. Give question title in text editor.
    4. If multiple langauges are selected, Switch the language in the right of text editor and repeat the steps 3 in the selected language.

#### 3. Number

To accept number response, you can use Number Question.

  To add Number Question,

    1. Click on `Add Content` in edit tab of selected Survey and then click on **`Number`** under Input Questions.
    2. A blank Number question will be created.
    3. Give question title in text editor.
    4. If multiple langauges are selected, Switch the language in the right of text editor and repeat the steps 3 in the selected language.

#### 4. Date

This allow respondent to give a Date from calender. 

 To add Date Question,

    1. Click on `Add Content` in edit tab of selected Survey and then click on **`Date`** under Input Questions.
    2. A blank Date question will be created.
    3. Give question title in text editor.
    4. If multiple langauges are selected, Switch the language in the right of text editor and repeat the steps 3 in the selected language.

#### 5. Photo

You can use Photo Question to get Images.
 
 To add Photo Question,

    1. Click on `Add Content` in edit tab of selected Survey and then click on **`Photo`** under Input Questions.
    2. A blank Photo question will be created.
    3. Give question title in text editor.
    4. If multiple langauges are selected, Switch the language in the right of text editor and repeat the steps 3 in the selected language.


#### 6. Multi Text Input

Multi Text Input provides the flexibility to add one or more custom text fields. This is more suitable when you have to create address like questions.

To add Multi Text Input Question,

    1. Click on `Add Content` in edit tab of selected Survey and then click on **`Multi Text Input`** under Input Questions.
    2. A blank Multi Text Input question will be created.
    3. Give question title in text editor.
    4. Give a key and display text for the field. Display Text is what respondent will see in the question. Key can only have alphanumeric or underscore. Then Click `Add Field`.
       Similarly you can add any number of fields.
    5. If multiple langauges are selected, Switch the language in the right of text editor and repeat the steps 3 & 4 in the selected language.

#### 7. File Input

You can use File Input Question to get any type of file. The file has size limit. It can only accept file having size upto 10mb.
 
 To add File Input Question,

    1. Click on `Add Content` in edit tab of selected Survey and then click on **`File Input`** under Input Questions.
    2. A blank File Input question will be created.
    3. Give question title in text editor.
    4. If multiple langauges are selected, Switch the language in the right of text editor and repeat the steps 3 in the selected language.
