# Survey Settings


##### General Settings
   - **Name:** This allows you to update the name of your survey.
   - **Selected Languages:** You can choose the languages in which your survey will be available.
   - **Selected Teams:** This setting might be relevant if your survey is associated with specific teams. You can select the teams that have access to this survey. Click `Save` to apply these changes on the site.

##### Kiosk Mode
   - Kiosk Mode is a feature that, when enabled, allows a survey to run in a continuous loop on a device.So when survey is completed by one person, it will redirect to start the survey for next person. It's particularly useful for scenarios like on-site feedback collection, where the survey needs to be available consistently.

##### Skip Preview
   - Enabling Skip Preview will bypass the preview screen that typically shows respondents a summary of their responses before final submission. If disabled, a confirmation preview screen will be shown to the user with their responses when the survey is finished.

##### Fetch Location
   - When enabled, this option allows the survey to fetch the location of the user. This can be useful for gathering geolocation data associated with survey responses. By default, this feature is disabled.

##### Unique Device Entry
   -  Allows only Single user entry from a device

##### Automatic Transition
   -  If enabled proceed to the next question automatically after making a selection

##### Redirect 
   - You can set redirection url and time in seconds. It will allow to redirect the survey to the specified url after given seconds.

##### Password Protection
   - You can add an extra layer of security to your survey by enabling password protection. This means that respondents will need to enter a password to access and complete the survey. You set the password to control access.

##### Email Notification
   - Enabling this feature will trigger email notifications. This can be useful for alerting survey administrators or other relevant parties when a survey response is submitted. Configure the email notification settings as needed.

##### Ticket
   - You can also enable/disable ticketing system and ticket email alerts in survey settings.

##### GoogleSheet
   - It will provide link to generated google sheet page if the result is synced to google sheet. 

##### Danger Zone
   - This is a cautionary section that warns about the consequences of clicking the `Reset Response Data` button. If you choose to clear survey response data and stats, it will permanently delete all the collected data. This action is irreversible, and the data cannot be recovered once cleared. This feature is typically used when a clean slate is needed for a survey.

Make sure to review and configure these settings based on the specific requirements and goals of your survey.
