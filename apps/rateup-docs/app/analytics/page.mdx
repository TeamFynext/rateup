Analytics in RateUp provides visibility into **team performance**, **agent productivity**, and **conversation trends**.  
It helps admins and managers make data-driven decisions and improve response efficiency.

---

## What You Can Track

- Total conversations and resolution rate
- Average response and first response time
- Agent availability and workload
- Conversation trends over time
- Channel-wise distribution
- Individual agent performance

---

## Analytics Sections

- **Overview** – High-level dashboard for team activity  
- **Agent Performance** – Detailed breakdown for each agent

Use the filters and date range selector to analyze performance over specific time periods.
