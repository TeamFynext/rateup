# Csv Upload

### Csv Upload Format

| categoryname   | name           | description                        | price          |
| :------------- | :------------- | :--------------------------------  | :------------- |
| Noodles        | Yakisoba       | A Japanese noodle stir-fry dish.   | 168            |

### Import Menu from CSV file

- Select "Import Menu" and modal will open
- Drag drop the csv file or click and select the file
- click Upload Csv
- Your Csv will be updated

*currency can be changed in the menu settings page, so mention your price in numbers*
