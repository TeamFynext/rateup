# Configure WhatsApp

You can Configure your whatsapp account for sending survey. To do that

Go to `Settings` under WhatsApp Survey section.

Provide following information:

1. Business ID
2. Phone ID
3. Access Token
4. Webhook password

And save the changes.

It will generate a Webhook URL. Copy the URL and paste it in your facebook app under whatsapp configuration @developers.facebook.com/apps/
