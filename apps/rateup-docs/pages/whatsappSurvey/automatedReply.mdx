# Automated Reply

It is used to provide an automated reply to users based on specific keywords they enter in a WhatsApp chat. When a user types any of the predefined keywords, the system will respond with the corresponding reply you have set up.

## create automated reply
 - Click on the `create automated reply` button, then provide the necessary details and click submit.

## delete
- Click on the `three dots` in the automated reply card from the list and select the `delete` button.
