# Tickets

Ticket is a facility to assign some task to any member within the organization.

### Create Tickets

Tickets can be created by click on the `create ticket` from Ticket section. 

Provide the information such as 
 - Ticket name
 - Description 
 - Selecte the person to assign
 - Team
 - Priority 
 - Deadline 

Once a ticket is created, an email will be sent to assigned person.

### Update Ticket

You can update following:

 - Assigned person
 - Priority
 - Status
 - Deadline

Tickets can be created from other features also.
