# Logic Jump in Surveys: A Guide to Personalized Responses

Logic Jump is a powerful feature that adds a layer of intelligence to your surveys in RateUp. It enables you to customize the survey experience based on respondents' answers, ensuring a personalized and relevant journey for each participant. By implementing Logic Jump, you can tailor subsequent questions based on the responses given, creating a more engaging and efficient survey process.

##### Questions supporting Logic Jump

1. Rating
2. Smiley
3. Yes or No
4. Like or dislike
5. Opinion scale
6. Multiple select
7. Single select
8. Dropdown Single select
9. Dropdown Multiple Select

##### How to add Logic Jump

1. Click on `Logic Jump` in the bottom of the question you want to add.
2. Click on `Add Logic Jump` and select condition and corresponding action.
3. save the changes.
