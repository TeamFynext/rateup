## Welcome Page

 The welcome page is the first impression respondents have when they access your survey. 


#### Enabling the Welcome Page

  The welcome page will be disabled by default. To customize it, you first need to enable it.

To Enable, Go to ` Theme ` tab in the selected survey and then switch to **`Welcome Page`**. You can enable it in the top right corner of welcome page window. 

#### Customizing Welcome Page

You can either create a new theme or use an existing theme. In order to create a new theme click on **`+`** icon in th right corner under select theme. Give
a proper name and click `Create`. If you are using an existing name, select a theme from the dropdown in th right corner under select theme.

You can customize following things in language page:

##### 1. Background
  
  - Select the `Background` from dropdown in the right panel
  - There are 2 options: 
      1. Use Survey Background: Background which is used in survey page theme will be used here.
      2. Choose the background,either color or image: If you have choosed image, then click on upload button and upload an image.    

##### 2. Title

Click on pencil icon on the right of title **Welcome**.  Give a suitable title according to your preference.

To change the font styles, 
  - Select `Title` from the right panel
  - Select the font weight from dropdown
  - Change the font size
  - Change the font color 
  

##### 3. SubTitle

Click on pencil icon on the right of subtitle **Please fill the survey**.  Give a suitable subtitle according to your preference.

To change the font styles, 
  - Select `SubTitle` from the right panel
  - Select the font weight from dropdown
  - Change the font size
  - Change the font color 

##### 4. Button

Click on pencil icon on the right of button **Start survey**.  Give a suitable text for the button according to your preference.

To change the button styles, 
  - Select `Button` from the right panel
  - Select a background color
  - Select a text color
  - Change position of button by selecting X axis and Y axis position.


#### Mobile View

In the top left corner, switch to the mobile view and repeat all the above process for changing mobile theme.

After making all the changes make sure to save the changes by clicking the `Save` button from top right corner.
