* Business Onboarding Flow

** 1) Meta Login Button
User clicks the Meta login button which opens a popup window and asks them to give permission to the the business account. It will also provide interface for selecting the phone number or to set up a new phone number.

After the login process we will get a 'code'.
** 2) Obtaining Business Integration System User Access Token
The 'code' obtained from the client in above step is send to our server. Then we will exchange this code with Meta to get an access_token.
** 3) Fetch & Save details of the new business client
With the above token we can obtain the waba_id & phone_id from /debug_token endpoint.
** 4) Registering the Whatsapp Business Account with our app
Then we make a POST request to {{waba_id}}/subscribed_apps with our app's systemUserToken. This will register the waBusinessAccount with our app.

All of the subscribed webhook events (including messages) will be now posted to our webhook endpoint
