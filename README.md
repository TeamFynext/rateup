# RateUp

Monorepo for the RateUp platform: API, dashboard, staff console, docs site, mobile app and
the Meta API mock. Built with [Vite+](https://viteplus.dev) and pnpm workspaces.

```bash
vp install          # Node 26, pnpm 12 (vp downloads it if needed)
pnpm run dev        # API + dashboard
vp run -r typecheck
```

See [AGENTS.md](AGENTS.md) for the layout and conventions, and each app's own README.
